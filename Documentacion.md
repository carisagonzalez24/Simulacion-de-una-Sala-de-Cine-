[Gestion de Tareas Pendientes en java

Este ejercicio consiste en desarrollar una aplicación en Java que permita administrar una lista de tareas pendientes. Se deben agregar funcionalidades como:
	1.	Agregar nuevas tareas a la lista.
	2.	Marcar tareas como completadas.
	3.	Mostrar todas las tareas.
	4.	Filtrar y mostrar solo las tareas pendientes usando Streams y Lambda.
  5.  Mostrar unicamente tareas incompletas.

Herramientas a utilizarse:
	•	ArrayList: Para almacenar las tareas en una lista.
	•	Streams y Lambda: Para filtrar las tareas incompletas.
	•	Scanner: Para recibir entrada del usuario y navegar por el menú e interactuar entre este mismo.

Objetivos a cumplir:
	•	Aprender a manejar ArrayList para la gestión de datos.
	•	Aplicar Streams y expresiones Lambda para filtrar listas de datos de manera eficiente.
	•	Usar Scanner para permitir la interacción con el usuario en un entorno de consola.

Este ejercicio permitirá gestionar una lista de tareas de manera interactiva y dinámica, aplicando conceptos clave de manipulación de colecciones y programación funcional en Java.]
